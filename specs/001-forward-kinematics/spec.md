**Input**: User description: "Phase 1 첫 기능으로 2-DOF 평면 매니퓰레이터의 관절 각도와
링크 길이를 입력받아 끝점 좌표를 계산한다. 입력 유효성, 수학적 정확성, 특이 자세와
경계 조건을 검증한다. IK, Jacobian, Target Tracking은 포함하지 않는다."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 알려진 자세의 끝점 위치 확인 (Priority: P1)

학습자는 두 관절 각도와 링크 길이를 입력해 기준 좌표계의 끝점 위치를 확인하고,
직관적으로 확인 가능한 자세의 해석적 기준값과 비교할 수 있다.

**Why this priority**: 이후 기구학 실습이 의존하는 최초 위치 계산이며, 독립적으로 유용하다.

**Independent Test**: 아래 기준 자세를 각각 계산하여 x와 y 성분의 절대 오차가 모두
1e-9 m 이하인지 확인한다. 기준값은 기하학적 길이 합·차와 방향으로 독립 확인한다.

**Acceptance Scenarios**:

| ID | Given: (l1, l2) [m] | When: (theta1, theta2) [rad] | Then: (x, y) [m] |
|----|---------------------|----------------------------|-----------------|
| A1 | (1.0, 0.8) | (0, 0) | (1.8, 0) |
| A2 | (1.0, 0.8) | (pi/2, 0) | (0, 1.8) |
| A3 | (1.0, 0.8) | (0, pi/2) | (1.0, 0.8) |
| A4 | (1.0, 0.8) | (pi/2, -pi/2) | (0.8, 1.0) |
| A5 | (0.5, 1.5) | (0, 0) | (2.0, 0) |
| A6 | (1.0, 0.8) | (-pi/2, 0) | (0, -1.8) |

### User Story 2 - 잘못된 입력의 명시적 거부 (Priority: P1)

학습자는 유효하지 않은 관절 각도나 링크 길이가 정상 위치로 해석되지 않고,
어떤 입력 조건이 위반되었는지 확인할 수 있다.

**Why this priority**: 잘못된 위치를 정상 결과로 사용하면 이후 실습의 결론을 신뢰할 수 없다.

**Independent Test**: 네 입력 각각에 비정상 값을 하나씩 넣고 나머지는 유효한 값으로
유지한다. 모든 경우 실패가 명시되며 정상 위치가 제공되지 않는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 다른 입력은 유효함, **When** l1 또는 l2에 0, -0.0, 음수를 입력함,
   **Then** 해당 링크 길이가 양수가 아님을 식별하는 실패를 제공한다.
2. **Given** 다른 입력은 유효함, **When** 네 입력 각각에 NaN, +무한대, -무한대를 입력함,
   **Then** 유한값 조건 위반을 식별하는 실패를 제공한다.
3. **Given** 스칼라 실수 입력이 필요함, **When** 문자열, 복소수, 불리언, 누락값 또는
   여러 값의 묶음을 단일 입력 대신 제공함, **Then** 입력 종류 위반을 명시한다.
4. **Given** 유한한 입력임, **When** 수치 표현 한계로 계산 결과를 유한하게 표현하지 못함,
   **Then** 수치 계산 실패를 명시하고 NaN·무한대 좌표를 정상 결과로 제공하지 않는다.

### User Story 3 - 접힘·펼침과 주기적 각도 검증 (Priority: P2)

학습자는 완전히 펴지거나 접힌 자세에서도 끝점 위치를 확인하고,
같은 자세를 나타내는 각도 표현이 동일한 위치를 주는지 검증할 수 있다.

**Why this priority**: 역문제의 특이 자세와 FK 계산 가능성을 혼동하지 않도록 한다.

**Independent Test**: 아래 기준값 및 주기 등가 쌍을 비교한다.
정상적인 수치 조건에서 각 좌표 성분의 절대 오차는 1e-9 m 이하이다.

**Acceptance Scenarios**:

1. **Given** (l1, l2) = (1.0, 0.8) m, **When** 각도가 (0, pi) 또는 (0, -pi) rad,
   **Then** 두 결과는 모두 (0.2, 0) m이다.
2. **Given** (l1, l2) = (1.0, 1.0) m, **When** 각도가 (0, pi) rad,
   **Then** 결과는 (0, 0) m이며 동일 길이 링크를 거부하지 않는다.
3. **Given** (l1, l2) = (0.8, 1.0) m, **When** 각도가 (0, pi) rad,
   **Then** 결과는 (-0.2, 0) m이다.
4. **Given** 기본 링크 길이, **When** 각도가 (pi, 0) 및 (-pi, 0) rad,
   **Then** 두 결과는 모두 (-1.8, 0) m이다.
5. **Given** 기본 링크와 각도 (0, pi/2), **When** theta1과 theta2 각각에 독립적으로
   2k*pi를 더함(k = -2, -1, 0, 1, 2의 모든 조합),
   **Then** 모든 결과는 기준 위치 (1.0, 0.8) m과 일치한다.
6. **Given** 기본 링크와 theta1 = 0, **When** theta2가 0 또는 pi의 양쪽에서
   1e-6 rad만큼 떨어진 값임, **Then** 유한 위치를 제공하고 각 위치의 기준값과 일치한다.
   기준값의 독립 계산 방식은 Plan에서 구체화한다.

### Edge Cases

- theta2 = 0, ±pi: 특이 자세라도 FK 위치 계산의 실패 조건으로 취급하지 않는다.
- l1 = l2 및 완전 접힘: 원점 위치는 유효한 FK 결과다.
- l1 < l2: 링크 순서에 따라 접힌 끝점이 음의 x 방향에 있을 수 있다.
- 음수 각도, ±pi 경계 및 정규 범위 밖의 주기 등가 각도를 허용한다.
- 유한한 양의 매우 작은·큰 링크 길이와 큰 각도는 입력값 자체만으로 거부하지 않는다.
  표현 한계에 따른 실패는 명시한다. 모든 크기의 입력에 같은 절대 오차를 보장하지 않으며,
  극단값 검증 사례·오차 근거·표현 한계 처리 방식은 Plan에서 정한다.
- 잘못된 입력을 clipping, 기본값 대체 또는 절댓값 변환으로 정상화하지 않는다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: theta1, theta2 [rad]와 l1, l2 [m]의 단일 스칼라 실수 입력으로
  기준 좌표계의 끝점 (x, y) [m]를 계산해야 한다.
- **FR-002**: Base (0, 0), x 오른쪽·y 위쪽·z 화면 밖의 오른손 좌표계,
  반시계 양의 회전을 적용해야 한다. theta1은 기준 x축 기준, theta2는 Link 1 기준
  상대 각도이다. 두 강체 링크의 해석적 기구학 관계로 끝점 위치를 결정해야 한다.
- **FR-003**: 두 링크 길이는 각각 유한한 양수, 두 관절 각도는 각각 유한한 실수여야 한다.
  위반 입력의 종류 또는 조건을 식별하는 실패를 제공하고 정상 위치를 반환하지 않아야 한다.
- **FR-004**: 잘못된 입력 종류 및 수치 표현 한계에 따른 실패를 명시해야 한다.
  실패 전달 방식과 구체 자료형은 Plan에서 정하되 User Story 2의 구분을 유지해야 한다.
- **FR-005**: 완전 펼침·접힘·근접 자세 및 동일 길이 링크를 정상 FK 입력으로 처리해야 한다.
  역문제의 특이점 때문에 위치 계산을 거부해서는 안 된다.
- **FR-006**: 각도에 임의의 하드웨어 관절 제한을 부과하지 않아야 한다.
  2pi 주기 등가성을 유지하고 ±pi의 표현 차이를 서로 다른 위치로 해석해서는 안 된다.
  정상 수치 조건에서의 검증은 A1–A6 및 User Story 3을 따른다.
- **FR-007**: 끝점 위치 계산은 그림 표시나 시뮬레이션 실행 없이 사용할 수 있어야 한다.
  동일한 입력과 환경에서 반복 계산한 결과는 동일해야 한다.
- **FR-008**: 수학적 정확성, 입력 거부 및 경계 조건을 검증하는 자동 테스트가 필수다.
  pytest 사용은 상위 문서와 Constitution의 필수 제약이며 선택 사항이 아니다.
  Plan·Tasks에는 모든 수용 시나리오를 테스트 작업과 연결해야 한다.
- **FR-009**: 검증에는 구현과 별도로 확인한 기준값을 사용하고,
  실행 명령·환경·의존성 버전·대상 Commit SHA·실제 결과·미실행 항목을 기록해야 한다.
  실행하지 않은 테스트를 통과로 기록해서는 안 된다.

### Key Entities *(include if feature involves data)*

- **Joint Configuration**: theta1, theta2와 각도의 기준·단위.
- **Link Geometry**: 순서가 있는 두 강체 링크의 길이 l1, l2와 길이 단위.
- **End-Effector Position**: Base 좌표계의 x, y와 위치 단위.
- **Validation Failure**: 위반 입력 조건 또는 수치 표현 한계로 위치를 제공하지 못한 결과.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 학습자는 A1–A6와 User Story 3의 기준값 사례 모두에서
  x와 y 각각의 절대 오차가 1e-9 m 이하인 끝점 위치를 얻는다.
- **SC-002**: User Story 2의 잘못된 입력 조합은 100% 명시적 실패로 판별되며
  정상 위치로 오인할 결과가 제공되지 않는다.
- **SC-003**: User Story 3의 주기 등가 비교 25개 조합과 ±pi 경계 비교에서
  각 좌표 성분의 차이가 1e-9 m 이하이다.
- **SC-004**: 동일 환경에서 A1–A6를 각각 3회 반복하면 각 사례의 좌표가 매번 동일하다.
- **SC-005**: 검증자는 모든 FR 및 수용 시나리오의 검증 방법·결과·대상 버전을 추적하고,
  기록된 입력과 명령으로 재검증할 수 있다. 미실행 항목은 통과 항목과 구분된다.

## Assumptions

- 사용자는 2R 평면 로봇의 기초 기구학을 학습한다. 기본 링크는 (1.0, 0.8) m이지만
  입력 가능한 링크를 기본값에만 제한하지 않는다.
- 범위는 한 자세의 끝점 위치 계산과 입력 검증·자동 테스트다. IK, Jacobian 계산,
  Target Tracking, 속도 제어, 애니메이션·시각화 구현, 동역학은 포함하지 않는다.
- 목표점 입력이 없으므로 도달 불가능 목표 판별은 이번 기능의 요구사항이 아니다.
- 문자열 등의 자동 변환 및 일괄 자세 계산은 요구하지 않는다.
  함수 이름·인자 순서·반환 자료형·예외 종류와 수치 처리 절차는 Plan의 설계 대상이다.
- 정규화 여부는 Plan에서 정하며 주기 등가성과 기준 자세의 정확성을 보존한다.
  큰 각도·극단적 길이에서의 수치 한계는 Plan에 명시하고 상위 수용 기준을 완화하지 않는다.
- 선행 구현 기능 의존성은 없다. 후속 IK·Jacobian·추종 기능이 사용할 기반이지만
  이들의 인터페이스나 알고리즘을 이번 Spec에서 결정하지 않는다.
- 추적 근거: PROJECT_PLAN.md §3(모델) → FR-001–006;
  §4 FK(위치 계산·입력 검증·시각화 분리) → FR-001–007;
